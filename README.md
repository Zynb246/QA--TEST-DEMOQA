# 🧪 DemoQA Test Automation Project

Bu layihə DemoQA vebsaytının test avtomatlaşdırılması üçün hazırlanmışdır.

## 📋 Layihə Haqqında
- **Test edilən sayt:** https://demoqa.com
- **Framework:** Selenium WebDriver + TestNG
- **Dil:** Java
- **Build Tool:** Maven

## ✨ Test olunan funksiyalar
- Elements (Text Box, CheckBox, Radio Button, Buttons, Links)
- Forms (Practice Form)
- Alerts, Frame & Windows
- Widgets (Accordian, Auto Complete, Date Picker, Slider, Progress Bar)
- Interactions (Sortable, Selectable, Resizable, Droppable, Dragabble)
- Book Store Application

## 🚀 Layihəni işə salmaq
1. Reponu klonla:
```bash
   git clone https://github.com/Zynb246/QA--TEST-DEMOQA.git
```
2. Dependencies yüklə:
```bash
   mvn clean install
```
3. Testləri işə sal:
```bash
   mvn test
```
